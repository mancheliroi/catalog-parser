# Catalog Parser — парсер каталога товаров с выгрузкой в Excel и CSV

Асинхронный парсер, который обходит каталог интернет-магазина, собирает карточки товаров и сохраняет их в аккуратную таблицу Excel или CSV. По умолчанию настроен на учебный магазин [books.toscrape.com](https://books.toscrape.com), созданный специально для практики парсинга.

## Что собирает

Название, цена и валюта, наличие и остаток, рейтинг, категория, артикул, описание, ссылка на товар.

## Возможности

- обход всех страниц каталога (пагинация) или только первых N;
- параллельная загрузка карточек с ограничением одновременных запросов и паузой — сайт не перегружается;
- повторы с нарастающей паузой при ошибках 5xx/429 и сбоях сети, без повторов на 404;
- битая карточка не роняет сбор — она попадает в список ошибок;
- удаление дублей ссылок;
- Excel с оформленной шапкой, фильтрами, закреплённой строкой и кликабельными ссылками;
- CSV сразу открывается в Excel с кириллицей (UTF-8 BOM, разделитель `;`).

## Стек

Python 3.12 · httpx (async) · selectolax (lexbor) · openpyxl · pytest · Docker

## Запуск

```bash
pip install -r requirements.txt

python -m parser                                   # весь каталог → data/products.xlsx
python -m parser --pages 3 --out data/books.csv    # первые 3 страницы в CSV
python -m parser --concurrency 10 --delay 0.1 -v   # быстрее, с подробным логом
```

Через Docker:

```bash
docker build -t catalog-parser .
docker run --rm -v "$PWD/data:/app/data" catalog-parser --pages 2
```

## Как адаптировать под другой сайт

Вся логика разбора HTML — в `parser/extract.py` (функции `parse_listing` и `parse_product`). Чтобы парсить другой магазин, достаточно поменять CSS-селекторы там; обход, повторы и выгрузка остаются без изменений.

## Тесты

Тесты не ходят в интернет: «сайт» подменяется через `httpx.MockTransport`.

```bash
pip install -r requirements-dev.txt
pytest
```

## Структура

```
parser/
  __main__.py   — командная строка
  crawler.py    — обход каталога, повторы, параллельность
  extract.py    — разбор HTML (селекторы сайта)
  export.py     — сохранение в Excel и CSV
tests/          — тесты разбора, обхода и выгрузки
```
